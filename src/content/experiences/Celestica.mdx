- **Vídeo e interfaces multimedia:** Automatización de pruebas de generación, captura y análisis de patrones de vídeo en interfaces
6G-SDI, 3G-SDI, DisplayPort y HDMI, validando funcionalidad, estabilidad y requisitos de señal.
- **Validación de interfaces de alta velocidad:** Ejecución de pruebas de estrés sobre Ethernet 10G mediante iperf3, evaluando tráfico
TCP/UDP y monitorizando métricas como rendimiento, jitter, estabilidad del enlace y errores de interfaz con ethtool.
- **Análisis de esquemáticos de placas:** CPU/GPU dentro de un sistema de computación, incluyendo interfaces digitales de alta
velocidad como PCIe y buses de comunicación CAN, RS-485, USB, I2C y SPI, para apoyar la preparación de pruebas de
verificación.
- **Automatización de pruebas:** Desarrollo de scripts y herramientas de verificación con Python, C++, C#, shell scripting, LabVIEW y
TestStand, utilizando SDKs específicos de componentes y entornos Linux/Windows para la interacción a bajo nivel y la validación
del sistema.
